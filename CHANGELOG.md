# История публичных версий Cita Por Favor

Здесь отмечаются только изменения, выпущенные в публичном репозитории. Полная
рабочая история разработки и личные диагностические заметки сюда не попадают.

## 9.25 — услугa asignación de NIE

- Новая услуга «ASIGNACIÓN DE NIE (Policía — первое получение номера)» —
  первичное назначение номера NIE: галочка в «Настройках поиска»,
  чередуется с остальными услугами как обычно. Для записи по этой услуге
  в «Изменить мои данные» выберите документ «Паспорт» — NIE у заявителя
  ещё нет.
- Фикс заполнения: при выборе «Паспорт» поле номера документа на сайте
  оставалось в формате N.I.E. и не принимало номер — теперь тип
  документа выбирается настоящим кликом, номер подставляется сразу.
- Спасибо за идею и проверку беты — Milana R.

## 9.24 — запись другому человеку при входе через Cl@ve

- При входе через Cl@ve/сертификат скрипт больше не привязан к владельцу:
  в «Настройках поиска» появился выбор «Кому записываемся» — «Себе (владелец
  Cl@ve)», как раньше, или «Другому человеку (из «Мои данные»)». При выборе
  «другому» кнопка «Copiar a datos solicitante» не нажимается, а имя, NIE
  и год рождения заявителя вписываются из «Моих данных»: своим сертификатом
  можно записать партнёра или члена семьи.
- Спасибо за идею и первую реализацию — Konstantin Chukreev (chukrello, PR #2).

## 9.23 — услуга recogida de tarjeta и экран подтверждения

- Новая услуга «RECOGIDA DE TARJETA (TIE)» — получение готовой карточки:
  в некоторых отделениях на это тоже нужна сита. Галочка — в «Настройках
  поиска», чередуется с остальными услугами как обычно.
- Экран «CITA CONFIRMADA» после Confirmar теперь распознаётся: зелёный
  статус «СИТА ПОДТВЕРЖДЕНА», тихая остановка проверки, запись в журнал.
- Любая остановка проверки теперь гарантированно глушит голосовое
  оповещение.

## 9.22 — выбор офисов галочками

- Секция «Офисы, которые проверяем»: вместо одного офиса из списка —
  галочки. Ничего не отмечено = вся провинция (запишетесь в любой офис со
  свободным слотом); один офис = проверка только его; два и больше =
  каждый заход проверяет всю провинцию, но записывает только в отмеченные
  офисы — чужие пропускает и продолжает проверку.
- Галка «Если выбранных офисов нет — брать любой» (видна при двух и более
  отмеченных офисах) разрешает записаться в любой предложенный офис.
- Записывать вас в чужой офис без этой галки скрипт больше не будет.

## 9.21 — поддержка и обратная связь

- Внизу панели появилась компактная кнопка «Написать в поддержку».
- В README и инструкции добавлены ссылки на GitHub Discussions и правила
  безопасной диагностики без личных данных.
- Тип документа выбирается из списка: NIE или PASSPORT.
- Страна больше не имеет значения по умолчанию: её задаёт сам пользователь.

## 9.20 — первый публичный выпуск

- Cita Por Favor опубликован как локальный userscript для проверки доступности
  citas в Барселоне.
- Добавлены публичные инструкции, правила приватности и безопасного
  использования.
