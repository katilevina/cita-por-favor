# История публичных версий Cita Por Favor

Здесь отмечаются только изменения, выпущенные в публичном репозитории. Полная
рабочая история разработки и личные диагностические заметки сюда не попадают.

## 9.21 — поддержка и обратная связь

- Внизу панели появилась компактная кнопка «Написать в поддержку».
- В README и инструкции добавлены ссылки на GitHub Discussions и правила
  безопасной диагностики без личных данных.
- Тип документа выбирается из списка: NIE или PASSPORT.
- Страна больше не имеет значения по умолчанию: её задаёт сам пользователь.

## 9.20 — первый публичный выпуск

- Cita Por Favor опубликован как локальный userscript для проверки доступности
  citas в Барселоне.
- Добавлены публичные инструкции, правила приватности и безопасного
  использования.
