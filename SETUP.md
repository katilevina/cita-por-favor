# Установка Cita Por Favor

## 1. Установите Tampermonkey

В Chrome откройте [Tampermonkey](https://www.tampermonkey.net/) и установите
расширение. После установки его значок появится рядом с адресной строкой.

## 2. Добавьте userscript

1. Откройте Tampermonkey → «Создать новый скрипт».
2. Удалите шаблонный текст.
3. Откройте файл `cita-autofill.user.js`, скопируйте его целиком, вставьте в
   редактор и сохраните.
4. Откройте страницу записи на сайте администрации. Внизу справа появится
   панель Cita Por Favor.

## 3. Настройте проверку

В панели выберите услуги, офис и способ входа. Личные данные сохраняются в
Tampermonkey только в вашем браузере. Выберите подходящий ритм проверки и
запустите его, когда вы готовы сами продолжить запись при появлении cita.

Не запускайте одну и ту же проверку одновременно в нескольких вкладках или
на нескольких компьютерах.

## 4. Необязательные уведомления macOS

Для голоса, системных уведомлений, локального журнала и снимков дважды
нажмите `Запустить-уведомления-сит.command`. Откроется окно Terminal — не
закрывайте его, пока нужна проверка. Команда использует только встроенный в
macOS Python и работает локально.

На Windows и Linux userscript работает без этой команды. В таком случае нет
голосовых уведомлений macOS, постоянного `journal.log` и снимков `snaps/`.

## Если панель не появилась

Проверьте, что Tampermonkey включён, скрипт сохранён без ошибок, а открытая
страница относится к сайту записи. После изменения скрипта обновите страницу.
