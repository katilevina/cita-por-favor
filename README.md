# Cita Por Favor

Локальный помощник для проверки доступности cita на toma de huellas и
expedición de tarjetas в провинции Barcelona. Он работает в вашем обычном
Chrome через Tampermonkey: проверяет наличие свободных записей в выбранном
вами ритме и сообщает о находке. Финальные действия всегда остаются за вами.

## Быстрый старт

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/) в Chrome.
2. Создайте в Tampermonkey новый скрипт, замените его содержимое файлом
   `cita-autofill.user.js` и сохраните.
3. Откройте страницу записи, выберите нужные услуги и параметры в панели
   Cita Por Favor.
4. Запускайте проверку только на одном своём компьютере одновременно.

Подробная установка: [SETUP.md](SETUP.md). О том, какие данные остаются на
вашем компьютере: [PRIVACY.md](PRIVACY.md). Ограничения и безопасное
использование: [SAFE_USE.md](SAFE_USE.md). История публичных версий:
[CHANGELOG.md](CHANGELOG.md).

## Помощь и обратная связь

- Общие вопросы и отзывы: [GitHub Discussions](https://github.com/katilevina/cita-por-favor/discussions).
- Личная помощь: кнопка «Написать в поддержку» на панели открывает Telegram автора.

Не публикуйте в Discussions NIE, паспортные данные, телефон, e-mail, SMS-код,
пароли, сертификаты, полный `journal.log` или HTML-снимки. Для диагностики
сначала удалите личные данные и приложите только нужный фрагмент.

## Если устанавливаете с помощью ИИ

Можно открыть этот репозиторий в ИИ-ассистенте и попросить: «Проведи меня по
установке Cita Por Favor по SETUP.md». Передавать ИИ свои NIE, телефон, e-mail,
SMS-код, пароль или сертификат не нужно: все личные поля вводятся только в
Tampermonkey на вашем компьютере.

## Необязательные уведомления macOS

На macOS можно двойным кликом запустить
`Запустить-уведомления-сит.command`. Тогда появятся голосовые и системные
уведомления, локальный `journal.log` и снимки в `snaps/`. Без этой команды
userscript всё равно работает — просто без этих дополнительных функций.
